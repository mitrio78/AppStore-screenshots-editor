# Screenshot Studio

Локальный веб-редактор витрин скриншотов для App Store и Google Play.
Построен на Next.js 15 + React + Tailwind (база — шаблон скилла
`app-store-screenshots`, расширен свободными элементами, фонами, тенями,
мультипроектами и JPG-экспортом).

## Запуск

```bash
npm install   # только первый раз
npm run dev   # → http://localhost:3000
```

## Что умеет

- **Мокапы устройств**: iPhone (класс 6,9″ = 17 Pro Max), iPad 13″, Android
  phone/tablet, feature graphic. Скриншот можно перетащить из Finder **прямо
  на рамку устройства** на холсте.
- **Мокап настраивается**: размер (в % холста, числом или ручками),
  положение, поворот, слой, кастомная тень (цвет/прозрачность/blur/смещение).
- **Фон кадра**: тема-пресет, сплошной цвет, градиент (стопы + угол),
  изображение (cover/contain/panorama, blur, прозрачность). Кнопка
  «Apply to all slides» раскатывает фон на всю деку.
- **Свободные элементы**: текстовые поля (шрифт, размер, вес, цвет,
  выравнивание, межстрочный, плашка-подложка) и картинки/стикеры/бейджи.
  Всё двигается, масштабируется, вращается; Backspace удаляет выбранное.
- **Шрифты**: в комплекте Inter, Oswald, Manrope, Montserrat, Rubik, PT Sans,
  Noto Sans (все с кириллицей, работают офлайн и встраиваются в экспорт) +
  загрузка своих .ttf/.otf/.woff2 кнопкой рядом с выбором шрифта.
- **Локализация**: тексты элементов хранятся по локалям; переключатель в
  тулбаре, незаполненные локали фолбэчатся на en. Пути скриншотов поддерживают
  плейсхолдер `{locale}`.
- **Проекты**: каждый проект — локальный файл `projects/<slug>.json`
  (пользовательские данные, по умолчанию игнорируются git). Переключатель в
  тулбаре: создать, дублировать как пресет, переименовать, удалить.
- **Экспорт**: PNG или JPG (с качеством), любой набор стандартных размеров
  стора и локалей, вся дека или текущий кадр. Один файл качается напрямую,
  набор — zip `<platform>/<device>/<WxH>/<locale>/NN-<layout>.<ext>`.
  Экспорт гонять в Chrome (Safari ненадёжен с foreignObject-рендером).
- **Undo/redo** ⌘Z / ⇧⌘Z, автосейв в файл + localStorage.

## Пользовательские данные

Проекты, загруженные скриншоты, фоны, пользовательские шрифты и локальные
выгрузки не коммитятся. Чистый клон сам создаст `projects/default.json` при
первом запуске. Для программной генерации витрин можно использовать
`scripts/seed-fitlinkpro.mjs` как пример.

## Деплой на VDS

```bash
docker build -t screenshot-studio .
docker run -d -p 127.0.0.1:3000:3000 \
  -v "$PWD/projects:/app/projects" \
  -v "$PWD/public/screenshots:/app/public/screenshots" \
  -v "$PWD/public/fonts:/app/public/fonts" \
  screenshot-studio
```

Write-API без авторизации — наружу только через reverse-proxy с basic auth.
