## Зачем нужен Screenshot Studio?

Screenshot Studio - это локальный web-редактор для команд и независимых
разработчиков, которым нужны повторяемые, редактируемые и экспортируемые
скриншоты для магазинов приложений. Проект построен на Next.js 15, React и
Tailwind CSS. Витрины хранятся как обычный JSON плюс локальные скриншоты,
фоны и шрифты.

## Быстрый старт

### macOS

Дважды кликните `start.command` в Finder. Скрипт установит зависимости при
первом запуске, поднимет локальный dev-сервер и откроет редактор в браузере.

Чтобы остановить сервер, нажмите `Ctrl+C` в окне терминала, открытом
`start.command`.

### Windows

Дважды кликните `start.cmd` в File Explorer. Скрипт установит зависимости при
первом запуске, поднимет локальный dev-сервер и откроет редактор в браузере
по умолчанию.

Чтобы остановить сервер, нажмите `Ctrl+C` в окне командной строки, открытом
`start.cmd`.

### Ручной запуск

```bash
npm install
npm run dev
```

Редактор будет доступен по адресу:

```text
http://localhost:3000
```

Если порт `3000` уже занят, Next.js автоматически выберет следующий свободный
порт.

## Возможности

- **Мокапы устройств**: iPhone, iPad, Android phone/tablet и Google Play
  feature graphic.
- **Drag-and-drop скриншоты**: можно перетащить скриншот приложения прямо на
  рамку устройства.
- **Редактируемое размещение мокапа**: меняйте размер, позицию, поворот,
  порядок слоев и внешний вид мокапа, включая цвет корпуса и свою тень.
- **Фоны слайдов**: темы, сплошные цвета, градиенты и изображения с режимами
  cover, contain и panorama.
- **Свободные элементы**: добавляйте текстовые поля и изображения/стикеры,
  перемещайте, масштабируйте, вращайте, меняйте порядок, дублируйте или
  удаляйте их.
- **Типографика**: шрифт, размер, насыщенность, цвет, выравнивание, высота
  строки, межбуквенный интервал, uppercase, прозрачность и фон текстового
  поля.
- **Режимы copy/paste**: копируйте и вставляйте текст вместе с форматированием
  или только текст с сохранением стиля целевого поля.
- **Применение шаблона**: применяйте макет активного слайда к остальной
  колоде, сохраняя собственный текст каждого слайда.
- **Просмотр витрины в ряд**: смотрите всю текущую колоду как горизонтальную
  карусель магазина, чтобы оценить последовательность визуально.
- **Локализация интерфейса**: переключайте UI редактора между английским,
  русским и японским; структура словарей готова для добавления других языков.
- **Локализация контента**: тексты и пути к скриншотам поддерживают локали;
  в путях можно использовать placeholder `{locale}`.
- **Встроенные шрифты**: Inter, Oswald, Manrope, Montserrat, Rubik, PT Sans и
  Noto Sans включены с поддержкой кириллицы и встраиваются в экспорт.
- **Пользовательские шрифты**: можно загружать `.ttf`, `.otf`, `.woff` и
  `.woff2` локально.
- **Экспорт**: экспорт одного слайда или всей колоды в PNG/JPG под выбранные
  размеры магазинов и локали.
- **Undo/redo**: используйте `Cmd+Z` и `Shift+Cmd+Z`.

## Локальные пользовательские данные

Файлы проектов, загруженные скриншоты, пользовательские фоны, загруженные
шрифты и локальные экспорты считаются пользовательскими данными и игнорируются
git.

Игнорируемые локальные данные:

- `projects/*.json`
- `public/screenshots/*`
- `public/backgrounds/*`
- `public/fonts/uploaded/*`
- `public/fonts/fonts.json`
- `exports/`, `exported/`, `downloads/` и сгенерированные zip-файлы экспорта

Чистый клон автоматически создаст `projects/default.json` при первом запуске.

## Файлы проектов

Каждая витрина хранится как отформатированный JSON:

```text
projects/<slug>.json
```

Редактор автоматически сохраняет изменения проекта на диск с небольшой
задержкой. Не редактируйте тот же JSON вручную, пока в браузере есть
несохраненные изменения этого проекта.

## Результат экспорта

При экспорте нескольких слайдов Screenshot Studio создает zip со структурой:

```text
<platform>/<device>/<WxH>/<locale>/NN-<layout>.<ext>
```

Экспорт одного слайда скачивается напрямую как один файл изображения.

Для надежного экспорта рекомендуется Chrome или другой Chromium-браузер,
потому что Safari может нестабильно рендерить `foreignObject`.

## Локальный деплой

```bash
docker build -t screenshot-studio .
docker run -d -p 127.0.0.1:3000:3000 \
  -v "$PWD/projects:/app/projects" \
  -v "$PWD/public/screenshots:/app/public/screenshots" \
  -v "$PWD/public/backgrounds:/app/public/backgrounds" \
  -v "$PWD/public/fonts:/app/public/fonts" \
  screenshot-studio
```

API записи намеренно сделан local-first. Если вы открываете приложение наружу,
поставьте его за reverse proxy с авторизацией.

## Codex Skill

В репозитории есть переиспользуемый Codex skill для агентов, которые работают
со Screenshot Studio:

```text
skills/screenshot-studio
```

Skill описывает локальную схему проекта, политику пользовательских данных,
типовые workflow витрин и шаги проверки.

Чтобы установить его для локального Codex на macOS или Linux, выполните из
корня репозитория:

```bash
mkdir -p ~/.codex/skills
ln -s "$(pwd)/skills/screenshot-studio" ~/.codex/skills/screenshot-studio
```

На Windows PowerShell выполните из корня репозитория:

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex\skills"
New-Item -ItemType Junction `
  -Path "$env:USERPROFILE\.codex\skills\screenshot-studio" `
  -Target "$PWD\skills\screenshot-studio"
```

Если junction создать нельзя, просто скопируйте папку:

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex\skills"
Copy-Item -Recurse -Force ".\skills\screenshot-studio" "$env:USERPROFILE\.codex\skills\"
```

После установки перезапустите Codex или откройте новый thread. После этого
можно просить Codex использовать `$screenshot-studio` при создании или
редактировании витрин.
